Command-pass protocol (used by Task 1 and Task 2):
1. Run each line from the repo root in block order. Never retype a command from memory: the transcript must carry the extracted text byte for byte.
2. Record one line per command in the transcript, layout `PASS | COMMAND | EVIDENCE` (COMMAND exactly as extracted, single spaces around the bars). A failing command gets a line starting with the word FAIL in the same layout. A finished pass contains no FAIL line: fix the cause and run the whole pass again into a fresh transcript.
3. Long-running commands keep their text; only how they are started changes, and the evidence says so: the emulator runs in the background (Bash `run_in_background`); `adb ... logcat` and `cargo run` run under `timeout` (exit 124 means it was still running and counts as success).

5. Evidence per command:

Evidence `booted sdk=36` (anything else is FAIL).
   - `android/gradlew -p android assembleDebug`: exit 0 and `BUILD SUCCESSFUL`; evidence `BUILD SUCCESSFUL`.
   - `android/scripts/check-apk.sh`: evidence is its last line, `APK CHECK OK`.

   - `android/scripts/smoke.sh -s emulator-5554`: evidence is its last line, `SMOKE OK emulator-5554`.
   - `adb -s emulator-5554 install -r ...`: output contains `Success`; evidence `Success`.
   - `adb -s emulator-5554 shell am start ...`: no `Error` in the output and `adb -s emulator-5554 shell pidof ch.staeheli.dimuli` is non-empty; evidence `started pid=N`.
