```slint
export component EditorScreen inherits Rectangle {
    property <bool> settings-open: false;
    VerticalLayout {
        TopBar { }
        CollageCanvas { vertical-stretch: 1; min-height: Theme.canvas-min-height; }

    }
}
```

1. theme.slint: add `out property <length> side-panel-width: 300px;` in the Sizes group.
2. editor-screen.slint: add `property <bool> landscape: root.width > root.height;`. Portrait (`if !root.landscape`): exactly the current VerticalLayout. Landscape (`if root.landscape`): a VerticalLayout with `TopBar { }` on top and below it a HorizontalLayout holding `CollageCanvas { horizontal-stretch: 1; min-height: Theme.canvas-min-height; }` and a side column `Rectangle { width: Theme.side-panel-width; background: Theme.surface; }` that contains a `Flickable` whose viewport height follows the inner VerticalLayout's preferred height, with `TemplateBar { }`, the settings toggle button and `if root.settings-open: SettingsPanel { }` inside, so the expanded settings can be scrolled on a ~300 px high landscape phone. No editor hint text in landscape. `settings-open` stays a root property so the panel state survives rotation. To avoid duplicating the toggle, put it in a small non-exported component in the same file (like `SliderRow` in settings-panel.slint) that takes `in-out property <bool> open`. Keep all values from Theme; no logic beyond presentation.
3. Desktop check: first make sure the three test images exist (created in 05-01 and 05-03); recreate any missing one with `mkdir -p android/build/smoke` and `convert -size 1200x900 xc:'#d33' android/build/smoke/pick-a.jpg` (green `#3a3` pick-b.jpg, blue `#33d` pick-c.jpg).
